04 / TRANSPARENCIA

Modelo y metodología

Información que permite explicar y defender el prototipo durante la exposición.

01

Datos de entrenamiento

20 vuelos históricos ficticios: 8 con accidente y 12 sin accidente. Se usan cuatro variables numéricas y binarias.

02

Algoritmo

StandardScaler + LogisticRegression de Scikit-Learn. Los parámetros entrenados se exportan a JavaScript para realizar cálculos en el navegador.

03

Validación académica

Se evaluó mediante Leave-One-Out. La muestra reducida impide considerar el desempeño como evidencia de fiabilidad real.

Prototipo exclusivamente académico

El dataset es ficticio y demasiado pequeño para decisiones aeronáuticas. Las estimaciones no están calibradas ni validadas para su uso operativo. Las acciones sugeridas son orientativas para la demostración.
